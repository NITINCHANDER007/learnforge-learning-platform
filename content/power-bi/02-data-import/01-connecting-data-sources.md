---
title: Connecting Data Sources
---


Power BI can pull data from many sources: Excel files, CSV files, SQL databases, and web APIs.

**Get Data → choose source type → select tables → Load** (or **Transform Data** first to clean it before loading).

> **Tip:** Use **Transform Data** (which opens Power Query) to clean and reshape data *before* loading it — fixing issues at this stage is far easier than fixing them after building visuals on top of messy data.
