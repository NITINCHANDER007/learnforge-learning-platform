---
title: What is CSS?
---


CSS (Cascading Style Sheets) controls how HTML elements look — colors, fonts, spacing, layout.

```css
h1 {
    color: blue;
    font-size: 32px;
}
```

This says: "every `<h1>` element should be blue and 32 pixels tall." The **selector** (`h1`) targets elements; the **declarations** inside `{ }` set their styles.
