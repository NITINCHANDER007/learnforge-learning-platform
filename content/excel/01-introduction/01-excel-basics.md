---
title: Excel Basics
---


Excel organizes data into a grid of **cells**, referenced by column letter and row number (e.g. `A1`, `B2`). A collection of cells is a **worksheet**; a file containing one or more worksheets is a **workbook**.

> **Tip:** Get comfortable with keyboard navigation early — `Ctrl+Arrow` jumps to the edge of a data block, `Ctrl+Home` jumps to cell A1. These save enormous time once your sheets get large.
