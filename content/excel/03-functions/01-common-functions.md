title: Common Functions
---


```
=SUM(A1:A10)
=AVERAGE(A1:A10)
=COUNT(A1:A10)        counts numeric cells
=COUNTA(A1:A10)        counts non-empty cells (any type)
=IF(A1>50, "Pass", "Fail")
=MAX(A1:A10)
=MIN(A1:A10)
```

`IF()` is the most-used logic function in Excel — the pattern `=IF(condition, value_if_true, value_if_false)` appears constantly.
