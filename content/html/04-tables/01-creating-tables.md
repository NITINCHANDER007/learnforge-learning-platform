---
title: Creating Tables
---


```html
<table>
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>
    <tr>
        <td>Ada</td>
        <td>30</td>
    </tr>
</table>
```

`<tr>` is a table row, `<th>` is a header cell (bold, centered by default), `<td>` is a regular data cell.

**Common mistake:** using tables for page layout instead of actual tabular data — that's an outdated practice; use CSS (flexbox/grid) for layout instead.
