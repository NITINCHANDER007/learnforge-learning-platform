---
title: What is HTML?
---


HTML (HyperText Markup Language) is the standard language for structuring content on the web. Every webpage you've ever visited is built on HTML underneath, describing what each piece of content *is* — a heading, a paragraph, a link — not how it looks (that's CSS's job).

```html
<h1>My First Heading</h1>
<p>My first paragraph.</p>
```

> **Note:** HTML describes structure and meaning; CSS describes appearance. Keeping these separate is a core web development principle.
