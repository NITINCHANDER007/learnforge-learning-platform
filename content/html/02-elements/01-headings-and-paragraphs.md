---
title: Headings and Paragraphs
---


```html
<h1>Main Title</h1>
<h2>Subtitle</h2>
<h3>Smaller heading</h3>
<p>A paragraph of regular text.</p>
```

`<h1>` through `<h6>` represent heading levels, largest to smallest. Use only **one** `<h1>` per page (it represents the main title), and don't skip levels purely for visual size — use CSS for that instead, and headings to represent actual document structure.
