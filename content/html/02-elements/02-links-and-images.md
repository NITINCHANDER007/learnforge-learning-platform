---
title: Links and Images
---


```html
<a href="https://example.com">Visit Example</a>
<a href="/about">About Page</a>

<img src="photo.jpg" alt="A description of the photo">
```

- `href` is the destination URL of a link
- `src` is the image file path; `alt` is a text description — required for accessibility (screen readers read it aloud) and shown if the image fails to load

**Common mistake:** leaving `alt=""` empty on meaningful images — always describe what the image actually shows.
