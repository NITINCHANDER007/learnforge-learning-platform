---
title: Data Types
---


```javascript
let age = 25;              // number
let name = "Ada";          // string
let isActive = true;       // boolean
let items = [1, 2, 3];     // array
let person = { name: "Ada", age: 25 };   // object

console.log(typeof age);   // "number"
```

> **Note:** JavaScript has only one numeric type (`number`) for both integers and decimals — unlike Python's separate `int` and `float`.
