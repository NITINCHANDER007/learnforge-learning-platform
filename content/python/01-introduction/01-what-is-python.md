---
title: What is Python?
---


Python is a programming language. You write instructions, and the computer follows them, step by step.

People like Python because it reads almost like English. That makes it a great first language.

## Why learn Python?

- Used in web development, data science, automation, and AI
- Free and works on Windows, Mac, and Linux
- Huge community — if you get stuck, someone has probably asked the same question online

## A tiny taste

```python
print("Hello, World!")
```

This one line prints text to the screen. `print()` is a built-in function — a ready-made tool Python gives you.

> **Note:** Python is **case-sensitive**. `Print` and `print` are not the same thing.

## Common mistake

Beginners often forget the quotes around text:

```python
print(Hello)   # ❌ Error — Python thinks Hello is a variable name
print("Hello") # ✅ Correct — quotes mean "this is text"
```

## Interview tip

Interviewers sometimes ask "What kind of language is Python?" Good answer: *high-level, interpreted, dynamically typed, general-purpose.* You don't need to explain all four terms unless asked — just have them ready.

## Practice question

What will this print?
```python
print("2 + 2")
```
*(Answer: it prints the text `2 + 2`, not the number 4 — because it's inside quotes.)*
