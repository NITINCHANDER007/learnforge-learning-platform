---
title: Installation
---


To write and run Python code, you need Python installed on your computer.

## Steps

1. Go to **python.org/downloads**
2. Download the latest version for your operating system
3. During installation on Windows, **tick "Add Python to PATH"** — this one checkbox saves a lot of headaches later
4. Finish the install

## Check it worked

Open a terminal (Command Prompt, PowerShell, or Terminal on Mac) and type:

```bash
python --version
```

You should see something like `Python 3.12.0`.

> **Note:** On Mac/Linux, you may need to type `python3` instead of `python`.

## Common mistake

Forgetting to add Python to PATH means typing `python` in the terminal does nothing, or gives a "not recognized" error. If that happens, reinstall and tick the PATH checkbox, or search "add Python to PATH" for your OS.

## Tip

You don't have to use a fancy code editor to start. Even Notepad works. Once you're comfortable, tools like **VS Code** make coding much easier (auto-complete, error highlighting).
