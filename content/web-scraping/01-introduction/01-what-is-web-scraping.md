---
title: What is Web Scraping?
---


Web scraping means programmatically extracting data from websites, instead of copying it by hand.

A typical scraping pipeline: **request** a page's HTML → **parse** it to find the data you want → **store** it (CSV, database, etc.).

> **Note:** Not every site wants to be scraped — always check a site's `robots.txt` file and Terms of Service before scraping it.
